# Recollect_Front

Recollect_Front는 Expo와 TypeScript를 사용하여 개발된 React Native 모바일 애플리케이션입니다.

## 🚀 기술 스택

- **Framework**: [Expo](https://expo.dev/) ~54.0.27
- **Language**: TypeScript ~5.9.2
- **React**: 19.1.0
- **React Native**: 0.81.5

## 📋 필수 조건

- Node.js (>= 20.19.4 권장)
- npm 또는 yarn
- Expo CLI

## 🛠️ 설치 방법

1. 저장소 클론:
```bash
git clone https://github.com/parksungrae/Recollect_Front.git
cd Recollect_Front
```

2. 의존성 설치:
```bash
npm install
```

## 🎯 실행 방법

### 개발 서버 시작
```bash
npm start
```

### 플랫폼별 실행
```bash
# Android
npm run android

# iOS
npm run ios

# Web
npm run web
```

## 📱 Expo Go 앱으로 테스트하기

1. 스마트폰에 [Expo Go](https://expo.dev/client) 앱 설치
2. `npm start` 명령어 실행
3. QR 코드 스캔하여 앱 실행

## 📂 프로젝트 구조

```
Recollect_Front/
├── App.tsx              # 메인 애플리케이션 진입점
├── index.ts             # Expo 앱 등록
├── app.json             # Expo 설정 파일
├── tsconfig.json        # TypeScript 설정
├── package.json         # 프로젝트 의존성
├── assets/              # 이미지, 폰트 등 정적 리소스
└── node_modules/        # npm 패키지
```

## 🔧 개발 환경

이 프로젝트는 TypeScript의 strict 모드를 사용하여 타입 안정성을 보장합니다.
